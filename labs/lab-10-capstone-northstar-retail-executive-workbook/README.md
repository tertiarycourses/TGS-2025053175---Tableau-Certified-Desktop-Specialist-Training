# Lab 10 — Capstone: Northstar Retail Executive Workbook

**Scenario:** Northstar Retail's COO needs an executive workbook that reconciles sales, returns, inventory and regional targets, then communicates actions across desktop and mobile.

**Goal:** Integrate all four exam domains and complete certification-readiness evidence

**Data:** `Lab-10-Northstar-Retail-Capstone.xlsx` (synthetic mock data)

**Starter Tableau workbook:** `starter.twb`

## Detailed procedure

1. **Connect to Lab-10-Northstar-Retail-Capstone.xlsx.**
   Read the Executive Brief, Data Dictionary, table grains and Control totals.
2. **Build the logical data model.**
   Relate Orders, Returns, Products, Stores and Monthly Targets with documented keys and grains.
3. **Validate the source.**
   Check row counts, unmatched keys, duplicated sales, date range and control totals.
4. **Create core calculations.**
   Net Sales, Gross Profit, Profit Ratio, Return Rate, Target Attainment and Days to Ship.
5. **Demonstrate field concepts.**
   Document dimensions/measures, discrete/continuous date behaviour and aggregation changes.
6. **Build eight worksheets.**
   KPI text table, regional bar, monthly line, product scatter, map, highlight table, return set analysis and target reference view.
7. **Use groups, sets and a hierarchy.**
   Group store formats, create a Top-20 Products set and Region > Country > Store hierarchy.
8. **Apply analytics.**
   Add a running total, percent of total, reference line, histogram and parameter-driven measure swap.
9. **Build Executive Overview dashboard.**
   Use KPI tiles, four priority views, purposeful filters and at least two actions.
10. **Create a phone layout.**
   Prioritise KPI, trend and exception list for the smaller screen.
11. **Create a three-point story.**
   Performance, diagnostic evidence and recommended action.
12. **Package and export.**
   Save TWBX; export PDF and PowerPoint snapshots labelled with the reporting period.
13. **Complete the Exam Domain Matrix.**
   For every official objective, cite the workbook sheet or lab evidence that proves readiness.
14. **Run the acceptance checklist.**
   Test default, filter, action, clear, mobile, export and underlying-data states.
15. **Save as Lab-10-Northstar-Capstone.twbx.**
   Submit the workbook, exports, validation evidence and readiness matrix.

## Acceptance test

Control totals reconcile, the model avoids duplicated measures, all eight worksheets and required analytics exist, dashboard/actions work on desktop and phone, exports are current, and every official objective has evidence.

Complete `acceptance-checklist.md` and save evidence in an `evidence/` subfolder.
